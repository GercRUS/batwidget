# BatteryWidget

Лёгкий виджет батареи для Android 8+ (без сторонних библиотек).

- >50% зелёный, 15–50% жёлтый, <15% красный
- при зарядке вместо % — ток (мА) и примерное время до полной зарядки
- APK: вкладка Actions → Build APK → artifact `battery-widget-apk`
- Локально: открыть в Android Studio или `gradle assembleDebug`
